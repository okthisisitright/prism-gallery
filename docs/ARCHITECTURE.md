# Architecture and engineering notes

One native Android app module, with package boundaries for `core/model`, `core/media`, `core/database`, `core/security`, `core/designsystem` and each feature. Kotlin/Compose; no web shell or backend. `PrismApplication` owns application-scoped repositories and a single Room database. `LibraryViewModel` exposes StateFlows; Compose collects with lifecycle awareness. Navigation Compose retains destination state. A public viewer takes a metadata snapshot; secret state is never saved across process death.

MediaStore queries run on IO, consume closable cursors, check cancellation between rows, and publish batches of 500 lightweight records. The complete accessible metadata set is held in memory; this is **not database-backed paging**. Lazy grids and Coil size thumbnail decoding independently. No mass full-resolution decode. A ContentObserver and on-resume refresh track changes. Full-image display always uses `ContentScale.Fit`; ExoPlayer uses `RESIZE_MODE_FIT`. EXIF is handled by Coil and explicitly by the private decoder. Crop is used only for tiles/covers.

Membership identity hashes volume, MediaStore database version, ID, generation-added (API 30+), date-added, filename and byte size. This intentionally favors a missing membership after external renaming/editing over reassociation to an unrelated reused ID. Volume remounts, database rebuilds, or metadata-changing edits can leave unavailable memberships. They are retained, excluded from accessible counts, and never used to grant access. Identical legacy metadata can still collide; Android offers no universal immutable media UUID. Category deletion cascades only membership rows. Favorites remain independent. Multi-membership inserts are transactional and duplicate-safe.

Backdrop 2.0.1 captures a single content layer; floating navigation and viewer chrome sample that layer. Grids do not have a shader per tile. High uses blur, vibrancy and lens refraction; Balanced uses blur; Reduced uses layered solid translucency, edge highlights and shadows. Auto uses Balanced on Android 13+ except low-RAM devices. This is a capability heuristic, **not live frame-time adaptation**. Manual modes fall back on unsupported Android versions. Manrope is bundled under OFL. Motion is modest and respects Compose's system duration scale. No frame-rate claim is made.

ExoPlayer belongs to the active page and is released on disposal. It pauses when the activity pauses and manages audio focus. File copies use a user-selected SAF directory; partial destination files are deleted on failure. Copies never mutate the source. Android 11+ trash/deletion uses system requests. Android 10 supports recoverable single-file delete authorization. Android 8/9 permanent deletion requires granted legacy write permission; failure is reported. Vault source deletion is always permanent (trash would still retain plaintext).

Current limitations: metadata is not persisted/paged; date headers are not sticky; no shared-element viewer transition; no zoom animation/velocity-based fling; no direct move or rename of public files; category ordering uses earlier/later controls, not dragging; no per-category sort preference; no offline semantic model. Private viewer fits correctly but does not implement pinch/page gestures, private categories, or private renaming. Ordinary public browsing is restored at destination/grid level; a fullscreen viewer and unfinished dialogs close on process recreation/resume. Hardware-specific performance and Vivo/Funtouch behavior need device testing.
